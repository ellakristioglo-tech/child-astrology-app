# Security Policy

## Supported version

Only the latest version deployed from the `main` branch of `ellakristioglo-tech/child-astrology-app` is supported.

## Reporting a vulnerability

Do **not** open a public GitHub issue for a suspected vulnerability.

Report it privately by email to `ellakristioglo@gmail.com` with the subject `Child Astrology security report`. If GitHub private vulnerability reporting is available, you may instead use **Security → Advisories → Report a vulnerability** in this repository.

Please include:

- the affected URL, file, or feature;
- clear reproduction steps;
- the possible impact, especially whether child or parent data may be exposed;
- screenshots or a minimal proof of concept with personal data removed;
- a safe way to contact you for follow-up.

Do not access, retain, change, or share data belonging to another person. Use only your own test data.

## Response

We aim to acknowledge a report within 7 calendar days and provide a status update within 14 calendar days. A confirmed issue will be prioritised according to its impact on confidentiality, integrity, availability, and child data.

## Disclosure

Please allow reasonable time for investigation and remediation before public disclosure. Security reports will be handled confidentially as far as reasonably possible.

## Scope

The production application is [https://childastrologyapp.com/](https://childastrologyapp.com/). Third-party services such as GitHub Pages, Google Analytics, WhatsApp, and email providers are governed by their own security programmes unless the issue is caused by this application's configuration or code.
